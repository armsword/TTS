# HiFi-GAN 声码器原理文档

## 1. 概述

HiFi-GAN 是一个用于从梅尔频谱生成高保真音频波形的生成对抗网络（GAN）。它由韩国首尔大学的研究者提出，相比之前的 WaveNet、Parallel WaveGAN 等声码器，在保持高音质的同时大幅提升了生成速度。

## 2. 架构

### 2.1 整体结构

```
梅尔频谱 (batch, 80, time)
    ↓
输入卷积 (80 → 256)
    ↓
[上采样 ConvTranspose1d + ResBlock] × 4
    ↓
输出卷积 + tanh 激活
    ↓
波形 (batch, 1, time')
```

### 2.2 上采样率

| 层 | 上采样率 | 输入通道 | 输出通道 |
|----|----------|----------|----------|
| 1  | 8        | 256      | 128      |
| 2  | 8        | 128      | 64       |
| 3  | 2        | 64       | 32       |
| 4  | 2        | 32       | 16       |

总上采样率：8 × 8 × 2 × 2 = 256

### 2.3 残差块 (ResBlock)

每个残差块包含 3 个膨胀卷积，膨胀率分别为 1, 3, 5：

```
输入 → [Conv(dilation=1) → ReLU] → + → 输出
      → [Conv(dilation=3) → ReLU] → +
      → [Conv(dilation=5) → ReLU] → +
```

使用残差连接帮助梯度流动，使网络能够学习更深的表示。

## 3. 损失函数

HiFi-GAN 使用对抗训练，包含：

### 3.1 生成器损失
- **梅尔频谱重建损失**：L1 损失比较生成波形和真实波形的梅尔频谱
- **对抗损失**：让判别器认为生成样本是真实的

### 3.2 判别器损失
- 多尺度判别：使用多个判别器在不同尺度上判断
- 特征匹配损失：匹配真实和生成样本在判别器中间层的特征

## 4. 配置参数

| 参数 | upsample_rates | 总上采样率 |
|------|----------------|------------|
| 默认值 | (8, 8, 2, 2) | 256 |

对于 22050Hz 采样率、50 帧梅尔频谱：
- 输出长度 = 50 × 256 = 12800 样本
- 约 0.58 秒音频

## 5. 输入输出

- **输入**：梅尔频谱 (batch, n_mels=80, time)
- **输出**：波形 (batch, 1, time × 256)

## 6. 在 VITS 中的作用

VITS 使用 HiFi-GAN 作为声码器，将模型输出的梅尔频谱转换为可听的音频波形。整个 TTS 流程：

```
文本 → 音素 → 文本编码器 → 时长预测 → 展长 → VAE 采样 → 解码器 → 梅尔频谱 → HiFi-GAN → 波形
```

## 7. 与其他声码器对比

| 声码器 | 音质 | 速度 |
|--------|------|------|
| WaveNet | 高 | 慢（自回归） |
| Parallel WaveGAN | 中 | 快 |
| HiFi-GAN | 很高 | 很快 |
