# 时长预测器原理文档

## 1. 概述

时长预测器（Duration Predictor）是 VITS 模型中连接文本编码器和解码器的关键组件。它的作用是预测每个音素（phoneme）在最终梅尔频谱中应该占据多少个时间步。这解决了传统 seq2seq 模型（如 Tacotron）的自回归解码慢的问题。

## 2. 架构

### 2.1 组件结构

```
编码器输出 (batch, time, 192)
    ↓
[Conv1d(3x1) + ReLU] × 2层
    ↓
LayerNorm
    ↓
Linear(192 → 1)
    ↓
exp() 激活（确保正值）
    ↓
时长预测 (batch, time)
```

### 2.2 卷积层

使用 2 层 Conv1d 进行局部特征提取：
- kernel_size=3, padding=1：保持时间维度不变
- 捕获相邻音素的上下文信息

### 2.3 LayerNorm

在时间维度上应用 Layer Normalization，有助于训练稳定性。

### 2.4 输出层

- 使用线性层输出每个位置的原始预测值
- 通过 `exp()` 激活确保时长为正数
- 使用 `clamp(min=1.0)` 防止时长过小

## 3. regulate_length 函数

### 3.1 作用

根据预测的时长将编码器输出展开到正确长度：

```
输入: encoder_output (1, 3, 192), durations = [2, 3, 1]
输出: (1, 6, 192)

时间步映射:
t=0 → 位置 0, 1 (重复2次)
t=1 → 位置 2, 3, 4 (重复3次)
t=2 → 位置 5 (重复1次)
```

### 3.2 Batch 处理

- 计算 batch 内最大长度进行 padding
- 对每个样本独立展开
- 不足的位置保持为 0

## 4. 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| in_channels | 192 | 输入通道数（与 TextEncoder hidden_dim 一致） |
| n_layers | 2 | 卷积层层数 |

## 5. 输入输出

- **输入**：
  - `x`: (batch, time, 192) 编码器输出
  - `x_mask`: (batch, 1, time) mask

- **输出**：
  - `duration`: (batch, time) 每个位置预测的时长

## 6. 在 VITS 中的作用

1. **训练阶段**：
   - 预测时长与真实时长计算 L1 损失
   - 用于端到端训练

2. **推理阶段**：
   - 预测时长用于展开编码器输出
   - 展开后的序列长度与目标梅尔频谱长度匹配
   - 避免了自回归解码，大幅提升推理速度

## 7. 与传统方法的对比

| 方法 | 时长预测 | 解码速度 |
|------|----------|----------|
| Tacotron | 无（自回归） | 慢 |
| FastSpeech | 有 | 快 |
| VITS | 有（隐式） | 快 |
