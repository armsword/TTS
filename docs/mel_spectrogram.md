# 梅尔频谱原理文档

## 1. 概述

梅尔频谱（Mel Spectrogram）是语音处理中广泛使用的音频特征表示，它将原始音频波形转换为人耳感知更相关的频率表示。

## 2. 梅尔刻度 (Mel Scale)

人耳对频率的感知不是线性的，而是接近对数刻度。梅尔刻度是对这一特性的数学建模：

```
m = 2595 * log10(1 + f / 700)
```

其中 `f` 是线性频率（Hz），`m` 是梅尔频率。梅尔刻度使得低频分辨率高，高频分辨率低，这与人类听觉特性相符。

## 3. 梅尔频谱计算流程

### 3.1 短时傅里叶变换 (STFT)

1. **分帧 (Framing)**：将长音频切分成短帧（通常 20-40ms）
2. **加窗 (Windowing)**：对每帧应用汉宁窗或汉明窗减少频谱泄漏
3. **FFT**：对加窗后的信号进行快速傅里叶变换

### 3.2 梅尔滤波器组 (Mel Filter Bank)

将线性频谱通过一组梅尔滤波器组转换为梅尔频谱：

```
S_mel = Σ_k S(k) * H_m(k)  for m = 1, 2, ..., M
```

其中：
- `S(k)` 是 FFT 后的功率谱
- `H_m(k)` 是第 m 个梅尔滤波器的频率响应
- `M` 是梅尔滤波器数量（本项目使用 80 个）

### 3.3 对数变换

```
S_db = 20 * log10(S_mel)
```

取对数后便于后续神经网络处理。

## 4. 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| sample_rate | 22050 | 采样率 (Hz) |
| n_fft | 1024 | FFT 窗口大小 |
| hop_length | 256 | 相邻帧之间的采样数 |
| n_mels | 80 | 梅尔滤波器数量 |

## 5. 输出形状

输入：`(batch, time)` 或 `(time,)` 波形 tensor
输出：`(n_mels, time_steps)` 梅尔频谱 tensor

时间步数计算：
```
time_steps = (sample_rate * duration - n_fft) / hop_length + 1
```

## 6. 实现细节

本项目使用 `torchaudio` 的 `MelSpectrogram` 变换，它：
1. 自动进行 STFT 计算
2. 应用梅尔滤波器组
3. 返回梅尔功率谱

然后使用 `AmplitudeToDB` 将功率谱转换为分贝刻度。

## 7. 在 VITS 中的作用

在 VITS 模型中：
- 梅尔频谱作为解码器的目标输出
- 梅尔频谱通过 HiFi-GAN 声码器转换为最终波形
- 梅尔频谱的维度（80）决定了输出音频的频率分辨率
