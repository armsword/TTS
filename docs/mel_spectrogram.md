# 梅尔频谱原理文档

## 1. 概述

梅尔频谱（Mel Spectrogram）是 TTS 系统中音频信号的中间表示。它将原始波形转换为人耳感知相关的时频表示，既保留了语音的关键信息，又大幅降低了数据维度（从 22050 个采样点/秒 → 约 86 帧 mel/秒）。

## 2. 计算流程

```
原始波形 (22050 samples/sec)
    ↓ 分帧 (hop_length=256)
每帧 1024 个采样点，相邻帧重叠 768 个
    ↓ 加窗 (Hann window)
减少频谱泄漏
    ↓ FFT (n_fft=1024)
线性频谱 (513 频率 bins)
    ↓ 梅尔滤波器组 (80 个三角滤波器)
梅尔功率谱 (80 bins)
    ↓ AmplitudeToDB (10 * log10)
梅尔频谱 (80 bins, dB 刻度)
```

## 3. 核心概念

### 3.1 梅尔刻度 (Mel Scale)

人耳对频率的感知是**非线性**的：低频区分辨率高，高频区分辨率低。梅尔刻度数学建模了这一特性：

```
mel = 2595 × log₁₀(1 + f / 700)
```

| 线性频率 (Hz) | 梅尔频率 | 说明 |
|--------------|---------|------|
| 100 | 150 | 低频段变化缓慢 |
| 500 | 607 | |
| 1000 | 1000 | 定义点：1000 Hz = 1000 mel |
| 4000 | 2146 | 高频段压缩明显 |
| 11025 | 3589 | 奈奎斯特频率 |

### 3.2 梅尔滤波器组

80 个三角形滤波器在梅尔刻度上等间距排列，在线性频率轴上则低频密集、高频稀疏：

```
     /\        /\        /\         /\
    /  \      /  \      /  \       /  \
   /    \    /    \    /    \     /    \
  /      \  /      \  /      \   /      \
──────────────────────────────────────────── Hz
0   200   500   1k    2k     4k    8k   11k
  ← 密集 →            ← 稀疏 →
```

每个滤波器输出 = Σ(功率谱 × 滤波器权重)

### 3.3 分贝 (dB) 变换

功率谱的动态范围很大（10⁻⁵ ~ 10⁴），取对数压缩到人耳可感知的范围：

```
S_dB = 10 × log₁₀(S_power)
```

`torchaudio.AmplitudeToDB(top_db=80)` 还会将最大值以下 80dB 的部分裁剪掉，去除背景噪声。

## 4. 配置参数

| 参数 | 值 | 说明 |
|------|-----|------|
| sample_rate | 22050 Hz | 采样率 |
| n_fft | 1024 | FFT 窗口（46ms） |
| hop_length | 256 | 帧移（11.6ms） |
| n_mels | 80 | 梅尔滤波器数 |
| f_min | 0 Hz | 最低频率 |
| f_max | 11025 Hz | 最高频率（奈奎斯特） |
| top_db | 80 dB | 动态范围裁剪 |

### 4.1 时间分辨率

```
帧率 = sample_rate / hop_length = 22050 / 256 ≈ 86 帧/秒
每帧时长 = hop_length / sample_rate ≈ 11.6 ms
```

### 4.2 频率分辨率

```
频率分辨率 = sample_rate / n_fft = 22050 / 1024 ≈ 21.5 Hz/bin
```

## 5. 输入输出

- **输入**：波形 tensor (1, T) 或 (T,)，值范围 [-1, 1]
- **输出**：梅尔频谱 (80, T_frames)，dB 刻度

示例：1 秒音频 (22050 采样) → (80, 87) 梅尔频谱

## 6. 逆变换：从 Mel 重建音频

### 6.1 Griffin-Lim 算法

梅尔频谱只有幅度，丢失了**相位信息**。Griffin-Lim 通过迭代逼近：

```
初始化随机相位 φ₀
for i in 1..64:
    1. 用当前 (幅度, φᵢ₋₁) 做 ISTFT → 波形
    2. 对波形做 STFT → 新的 (幅度', φᵢ)
    3. 保留 φᵢ，替换幅度'为原始幅度
```

收敛后的相位使重建波形尽可能与给定幅度谱一致。

缺点：音质有"机器人味"，因为真实相位信息已不可逆地丢失。

### 6.2 HiFi-GAN 神经声码器

用神经网络直接从 mel 生成波形，不需要相位信息，音质远优于 Griffin-Lim。

## 7. 在 VITS 中的角色

```
训练:  wav → MelSpectrogram → mel_target  (监督信号)
推理:  model → mel_pred → Griffin-Lim/HiFi-GAN → wav  (音频重建)
```

梅尔频谱是连接"文本理解"和"音频生成"的桥梁。
